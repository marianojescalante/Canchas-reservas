# ⚽ Canchas-reservas - Sistema de Reservas de Fútbol

Sistema completo y profesional para la gestión de reservas de canchas de fútbol 5, 7 y 11.

## 🚀 Funcionalidades
- 📅 Calendario interactivo de reservas por hora
- ⚽ Gestión de múltiples canchas
- 👥 Registro y control de clientes
- 🔐 Panel de administración completo
- 📱 Diseño 100% responsive (anda perfecto en el celular)
- ⏰ Control de horarios disponibles y ocupados

## 💻 Tecnologías utilizadas
- PHP
- HTML5 / CSS3 / JavaScript
- MySQL (para futuro)
- GitHub

## 📍 Proyecto
Desarrollado por Mariano Escalante - Monte Chingolo, Buenos Aires.

Sistema ideal para complejos de canchas, clubes y centros deportivos.
